# Sistema de Pet Shop em C

Projeto acadêmico desenvolvido em linguagem C para gerenciamento de animais em um pet shop.

## Funcionalidades

- Cadastro de animais
- Listagem de animais
- Busca por ID
- Edição de cadastro
- Remoção de registros
- Contagem de animais cadastrados
- Persistência de dados em arquivo binário

## Tecnologias

- Linguagem C
- Structs
- Ponteiros
- Alocação dinâmica de memória
- Manipulação de arquivos
